# Teaching notes

- Prefers longer, source-driven sessions: each lesson gives a reading or viewing to do, then a quiz. Lessons can run longer than five minutes, but each still teaches one thing.
- Wants all theatres. Keep Asia in view from the start; don't let the course turn into Europe only.
- Course order (draft): 1 the two-wars skeleton → 2 causes (Versailles, the Depression, Hitler's rise, Japanese expansion, appeasement) → 3 Axis high tide, 1939–41 → 4 turning points of 1942–43 (Midway, Stalingrad, El Alamein) → 5 the road to victory, 1944–45 → 6 the Holocaust → 7 the aftermath. Revise against the learning records.
- Lessons are published together as one artifact ("WWII Field Course", `index.html` at the repo root) so the links between pages work. Republish to the same URL when lessons are added.
- Glossary: start `reference/glossary.html` once the user has used terms correctly (format: GLOSSARY-FORMAT). Candidates from lesson 1: Axis, Allies, theatre, Operation Barbarossa, V-E Day, V-J Day.
